The targeted npm override resolves Next.js’s nested PostCSS dependency to the existing root PostCSS 8.5.33. The clean install, installed dependency tree, and production build confirmed the resolution. This cleared the production audit findings without changing the Next.js major version.

The remaining advisory affects `minimatch` versions below 11.0.1 in the relevant range. The lint plugin requires minimatch 10, and npm proposes downgrading the plugin outside the current range. Keep the reviewed ESLint configuration and track a compatible upstream fix or a separately reviewed dependency change. [minimatch advisory](https://github.com/advisories/GHSA-g3hv-75wg-m249)
